# Heart Disease Prediction

A machine learning-based web application that predicts the likelihood of heart disease based on user-provided medical information. The application uses a Logistic Regression model trained with Scikit-learn and provides predictions through a FastAPI backend and a React frontend.

## Project Overview

The goal of this project is to demonstrate how machine learning can be integrated into a web application to analyze medical attributes and predict the possibility of heart disease.

Users can enter relevant health information through an interactive interface. The frontend sends the information to the backend API, where the trained machine learning model processes the input and returns a prediction.

## Features

- Predicts the likelihood of heart disease using a trained machine learning model.
- Interactive and user-friendly interface built with React and Bootstrap.
- REST API developed using FastAPI.
- Data preprocessing and feature scaling using Scikit-learn.
- Displays prediction results based on user input.
- Frontend and backend deployed separately using Vercel.

## Machine Learning Model

This project uses a Logistic Regression classification model to predict heart disease.

The model takes the following features as input:

| Feature | Description |
|---|---|
| Age | Age of the patient |
| Sex | Gender of the patient |
| Chest Pain Type | Type of chest pain |
| Resting Blood Pressure | Resting blood pressure |
| Cholesterol | Serum cholesterol level |
| Fasting Blood Sugar | Whether fasting blood sugar is above 120 mg/dl |
| Resting ECG | Resting electrocardiogram results |
| Maximum Heart Rate | Maximum heart rate achieved |
| Exercise Angina | Exercise-induced angina |
| Oldpeak | ST depression induced by exercise |
| ST Slope | Slope of the peak exercise ST segment |

Before making predictions, the input data is preprocessed and scaled using the same StandardScaler fitted during model training.

The trained model generates a prediction:

- `0` – No heart disease predicted.
- `1` – Heart disease predicted.

## API Endpoints

The backend provides the following endpoints:

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Checks whether the API is running |
| GET | `/health` | Checks backend and model availability |
| POST | `/predict` | Predicts heart disease based on input data |

### Prediction API

**Endpoint:**

```text
POST /predict
```

The endpoint accepts patient information in JSON format and returns a prediction result.
